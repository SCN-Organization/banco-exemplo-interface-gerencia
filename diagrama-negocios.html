Resumo das Classes

ICliente
Interface
  • Contrato de operações bancárias do cliente
  • creditar, debitar, transferir
  • procurarCliente / procurarConta
IGerencia
Interface
  • Estende ICliente
  • Operações administrativas do banco
  • cadastrar, associar, remover, atualizar
ContaAbstrata
Abstrata
  • Base de todas as contas
  • Campos: numero, saldo
  • debitar() é abstrato
  • Implements Serializable
Conta
Classe
  • Conta corrente simples
  • Lança SaldoInsuficienteException ao debitar
  • Saldo não pode ser negativo
ContaEspecial
Classe
  • Herda de Conta
  • Acumula bônus (1% a cada crédito)
  • renderBonus() credita e zera o bônus
Poupança
Classe
  • Herda de Conta
  • renderJuros(taxa) sobre o saldo atual
  • Implements Serializable (explícito)
ContaImposto
Classe
  • Herda diretamente de ContaAbstrata
  • CPMF = 0,38% incide em cada débito
  • Desconta valor + imposto
Cliente
Classe
  • Campos: nome, cpf
  • Lista de números de conta (String)
  • adicionarConta / removerConta
  • Implements Serializable
Banco
Singleton
  • Implements IGerencia + ICliente
  • Gerencia clientes e contas via repositórios
  • renderBonus (ContaEspecial)
  • renderJuros (Poupança)
